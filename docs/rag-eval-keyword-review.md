# kwiki-rag 关键词审阅清单

对 `src/main/resources/eval/datasets/kwiki-rag.jsonl` 自动抽取关键词的逐题人工审阅记录。
处置结果落在 `keyword-overrides.json`（按 id 覆盖），由 `tools/eval/build-kwiki-rag.mjs` 生成测试集时应用。

审阅依据：`dragonball-sample.json` 的 answer / references / keypoints 与语料 md 原文。规则：

- 答案本身的核心值优先（合计金额、结论中的数字/名称），不因 6 组上限被日期挤掉；
- 短语取完整词语，不在词中间截断，长度 2~10 字，优先能区分本题的实体（措施名、诊断名、人名、公司名），避开同类文档共有的套话；
- 每题 1~6 组，组内补常见别名；仍须出自来源文档原文、不出现在题干、多文档题每篇来源至少一组；
- 答案里由推理得出、原文没有的值（如「共 9 项」「合计 40 万元」）不作关键词，改用其组成项。
